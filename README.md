# Maasin SLP Egg Sales Tracker

A simple browser-based egg sales tracker for recording tray sales and calculating total income.

## Features

- Record trays sold, price per tray, sale date, and an optional customer name
- View all recorded sales in a table
- Calculate the total sales amount
- Responsive layout for desktop and mobile screens

## Run the App

1. Open `index.html` in a web browser.
2. Enter the sale details and select **Save sale**.

## Project Files

- `index.html` - Page structure and sales form
- `style.css` - Layout and visual styling
